# 🧠 AI-Powered Smart Attendance System

## 📌 Overview
The **AI-Powered Smart Attendance System** is an intelligent solution that automates the attendance process using facial recognition technology.  
It uses **OpenCV** for detecting and recognizing student faces and integrates with **Google Sheets API** to store attendance records in real time.  

This project eliminates manual roll calls, minimizes proxy attendance, and provides instant online attendance tracking for both faculty and students.

---

## 🚀 Features
- 📸 **Automatic Face Detection** using OpenCV  
- 🧍‍♂️ **Student Roll No. + Name Integration**  
- 💾 **Dataset Creation** for each student using a webcam  
- 🤖 **ORB Feature Matching** for lightweight facial recognition (no external ML libraries required)  
- ☁️ **Real-time Attendance Sync** with Google Sheets  
- 🧠 **No manual input needed** during recognition  
- 🔒 **Prevents proxy attendance**  
- 📊 **Easy access** to attendance data for teachers and students

---

## 🧰 Tech Stack
- **Python 3.10+**
- **OpenCV** (Standard CV2)
- **NumPy**

- **Google Sheets API**
- **gspread**
